# BarelySmash Core Values

> Version 1.0

These values guide every architectural decision, engineering tradeoff, and product choice within the BarelySmash Intelligence Platform.

---

# 1. Humans Decide

Technology augments judgment.

People remain accountable.

The platform exists to improve human decisions—not replace them.

---

# 2. Evidence Before Opinion

Every recommendation should be supported by observable evidence.

When evidence is weak, uncertainty should be communicated honestly.

---

# 3. Clarity Over Cleverness

A simple design that is understood is better than a clever design that is misunderstood.

Readable systems scale.

---

# 4. Learn Relentlessly

Every outcome is feedback.

Every mistake is data.

Every decision improves the next.

---

# 5. Explain Everything

Recommendations should be transparent.

Reasoning should be inspectable.

Confidence should be justified.

Black boxes are a last resort.

---

# 6. Respect Boundaries

Every component has one responsibility.

JARVIS coordinates.

Atlas understands operations.

Friday understands markets.

Applications present intelligence.

Shared infrastructure enables the platform.

---

# 7. Design for Time

Build systems that will still make sense ten years from now.

Optimize for maintainability before novelty.

Technology changes.

Principles endure.

---

# Engineering Principle

When faced with multiple solutions, choose the one that is:

- Easier to understand
- Easier to explain
- Easier to maintain
- Easier to compose
- Better for the human decision maker
